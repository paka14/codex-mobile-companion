# Changelog

Public versions identify source snapshots. Keep the package version, Git tag
(`v<version>`), and changelog in sync. A preview tag does not imply a packaged
installer, a stable release, or verified desktop compatibility.

## 0.1.0-preview.1

- First versioned source preview, based on `cd1247f`. No runtime changes from
  that baseline.
- Includes the Windows launcher and its read-only preflight, mobile conversation
  access, approvals, connection diagnostics, goal controls, and status badges.
- Clean Windows installation and real-phone operation are not yet verified.
